# 营养与代谢生理学参考文档 (Nutrition Science Reference)

本文档归档于 `references/`，供 Agent 在需要更深层次的生理代谢计算、饮食建议推导或用户问询时按需查阅（Progressive Disclosure）。

---

## 1. 基础代谢率 (BMR) 与总每日能量消耗 (TDEE)

### 1.1 Mifflin-St Jeor 公式 (1990)
本技能采用经临床营养学广泛验证的 Mifflin-St Jeor 公式估算 BMR (kcal/day)：

$$\text{BMR}_{\text{男}} = 10 \times \text{体重(kg)} + 6.25 \times \text{身高(cm)} - 5 \times \text{年龄} + 5$$
$$\text{BMR}_{\text{女}} = 10 \times \text{体重(kg)} + 6.25 \times \text{身高(cm)} - 5 \times \text{年龄} - 161$$

### 1.2 身体活动水平系数 (PAL / Physical Activity Level)
TDEE (Total Daily Energy Expenditure) 计算公式：$\text{TDEE} = \text{BMR} \times \text{PAL}$

| 活动量等级 | PAL 系数 | 判定参考（生活习惯与运动频率） |
| :--- | :---: | :--- |
| **久坐 (Sedentary)** | 1.200 | 伏案工作、无规律运动、日常活动极少 |
| **轻度 (Lightly Active)** | 1.375 | 每周 1~3 次轻度运动（如散步、快走、轻瑜伽） |
| **中度 (Moderately Active)** | 1.550 | 每周 3~5 次中等强度运动（如慢跑、力量训练、游泳） |
| **重度 (Very Active)** | 1.725 | 每周 6~7 次高强度运动或体力劳动者 |
| **极高 (Extremely Active)** | 1.900 | 每天剧烈运动、专业运动员或重度体力劳动 |

### 1.3 生理代谢安全底线 (Metabolic Safety Floors)
为了防范极低热量饮食（VLCD）诱发甲状腺功能受抑、游离睾酮断崖式下跌与去脂体重快速流失，系统设定了生理安全底线：
- **男性最低摄入底线**：$1,500\text{ kcal/day}$
- **女性最低摄入底线**：$1,200\text{ kcal/day}$
- 无论目标如何设为大幅减重，热量目标均强制不低于该安全底线。

## 2. 宏量营养素分配与循证定额

### 2.1 供能比模式 (Energy Ratio Mode)
- **维持期 (Maintenance)**：蛋白质 25%，碳水化合物 45%，脂肪 30%
- **减重 / 减脂期 (Fat Loss)**：蛋白质 30%，碳水化合物 40%，脂肪 30%
- **增肌 / 增重期 (Muscle Gain)**：蛋白质 30%，碳水化合物 45%，脂肪 25%

### 2.2 运动营养学蛋白质定额 (ISSN / ACSM Guidelines)
系统在计算目标时同步提供 `protein_g_per_kg`（每公斤体重蛋白质克数）：
- **大众一般健康**：$0.8 \sim 1.2\text{ g/kg}$
- **耐力训练人群**：$1.2 \sim 1.6\text{ g/kg}$
- **抗阻增肌与力量训练**：$1.6 \sim 2.2\text{ g/kg}$
- **低热量减脂保肌期**：$1.8 \sim 2.4\text{ g/kg}$

## 3. 烹饪方式热量与油脂修正模型

烹饪不仅改变食材质地，还会因吸附油脂大幅增加热量。本技能采用**仅缩放热量与脂肪**的后置修正模型，避免将食材本身的蛋白质与微量元素虚假放大。

| 烹饪手法 | 修正系数 | 生理与物理机制说明 |
| :--- | :---: | :--- |
| **白灼 / 清蒸 / 水煮 / 炖 / 凉拌** | 1.00 | 无额外附加油脂，营养值等于基础食材 |
| **清炒** | 1.10 | 少量起锅油（约 3~5g 油脂吸附） |
| **炒 / 爆炒 / 烧烤 / 烤 / 火锅** | 1.20 | 中等用油量，适度油脂吸附 |
| **红烧 / 煎 / 干煎 / 油焖 / 糖醋** | 1.35 ~ 1.40 | 较高油脂附着，糖醋含糖酱汁吸附 |
| **干煸** | 1.50 | 长时间高温煸炒，大量油脂吸收与失水浓缩 |
| **油炸 / 炸** | 1.70 | 油脂深度渗入面衣或食材肌理 |

*注：已是成品菜肴（如红烧排骨、蛋炒饭）不再重复叠加系数，防止热量双重溢价。*

## 4. 微量营养素与健康阈值 (WHO 指南)

1. **游离糖 (Free Sugar) vs 内源糖 (Intrinsic Sugar)**：
   - WHO 强烈建议限制**游离糖/添加糖**（白糖、果葡糖浆、浓缩果汁）摄入在总能量的 10% 以下（约 40~50g）。
   - 水果中的内源性果糖与纯牛奶中的乳糖与膳食纤维/蛋白质共存，升糖平缓，不属于重点限制范畴。
2. **钠 (Sodium)**：
   - 每日推荐摄入量上限为 $2,000\text{ mg}$ 钠（约合 $5\text{ g}$ 食盐）。
3. **膳食纤维 (Dietary Fiber)**：
   - 推荐每日摄入量为 $25 \sim 30\text{ g}$，有助于维持肠道微生态与平稳餐后血糖。
